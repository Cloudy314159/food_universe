# 同伴交叉验证材料（第 3 周验收 · Day 21）

> ⚠️ **这一项只能由你发起。** 交叉验证的意义就是"别人真的打开过"——
> 我自己跑的再多也不算交叉验证。下面的模板和话术是给你用的，
> **结论必须由同伴给出**。

---

## 一、发给同伴的话（整段复制，微信/QQ 直接发）

```
帮我测个东西，五分钟，我做的「想吃啥」，一个帮你决定中午吃啥的小网页：

https://model-d5gisaem106ad6a18-1500042790.tcloudbaseapp.com/

⚠️ 第一次打开会先弹一个「页面访问提示」，那是腾讯云给测试域名加的，
点「确定访问」就进去了，不是坏了。

麻烦按这四步走一遍：
1. 首页会直接给你推荐一家店或一道菜 —— 记住它叫什么
2. 点上面「我的清单」，看看一共列出多少条
3. 点「添加」，随便加一个你爱吃的（比如你家楼下那家店），点「保存」
4. 加完之后按 F5 刷新页面，再点「我的清单」，看你刚加的那条还在不在

然后回我三句话就行（照着填）：
1. 能否打开：      能 / 不能 ——（不能的话，卡在哪一步）
2. 能否真实读写：  能 / 不能 ——（第 3 步加进去了吗？第 4 步刷新后还在吗？）
3. 有无报错：      无 / 有 ——（有的话，按 F12 把 Console 里的红字截给我）

不用担心加错东西，这是测试库，随便加。谢谢！
```

**几个刻意的设计**（你发之前可以想一下为什么这么写）：

| 写法 | 为什么 |
|---|---|
| 先说「五分钟」 | 降低对方心理门槛，不然没人愿意点 |
| **提前说明拦截页** | 不给提示的话，90% 的人看到那页就以为打不开、直接放弃了 |
| 让他**自己加一个**、而不是"试试能不能加" | 有具体目标才会真动手 |
| 第 4 步要求**刷新后还在** | 这是"真写入"和"只是页面显示了一下"的分界线 |
| 明确说「随便加，是测试库」 | 不然他会怕搞坏你的东西 |
| 让他按 F12 | 普通用户不会主动看控制台，"有无报错"这一行得单独要 |

## 二、三行结论模板（同伴填这个）

```
第 3 周交叉验证 · 验证人：__________ · 时间：__________

1. 能否打开：      能 / 不能        —— 备注：
2. 能否真实读写：  能 / 不能        —— 备注：
3. 有无报错：      无 / 用 F12 看到  —— 备注：

（可附加一句话：作为用户，用起来最别扭的地方是 __________）
```

> 最后那句附加项是**可选**的。要了会更有价值 —— 你自测的时候已经知道哪些地方"我觉得还行"，
> 但别人觉得别扭的地方，往往是你自己看不见的。

## 三、对照表：同伴每一步该看到什么

你自己先按这份表走过一遍（我已经替你走通了，结果在最后一列），
这样同伴说"卡在某一步"时，你能立刻判断是**他操作的问题**还是**网站真有问题**。

| 步骤 | 应该看到 | 常见的不对劲 |
|---|---|---|
| 打开链接 | 先弹「页面访问提示」→ 点「确定访问」→ 进入首页 | 一直停在提示页 = 没点按钮，不是故障 |
| ① 首页 | 一张大卡片，写着某个店/菜的名字 + 底部「换一个」按钮 | 卡片空白 = 真的有问题（要看 F12） |
| ② 我的清单 | 一堆卡片，每张上有一条条目的名字 | 显示 0 条 = 接口没拉到数据 |
| ③ 添加 → 保存 | 页面下方出现「已加入：「XXX」」 | 出现红字中文提示 = 后端在拦（比如名字重复了） |
| ④ F5 刷新 + 看清单 | 刚加的那条**还在**列表里 | 刷新后没了 = 写入没落库（严重） |

**我这边实测的结果（网络正常时应该是这样）**：

| 检查 | 实测值 |
|---|---|
| 首页 | 推荐卡显示「兰州拉面」，底部写「共 19 个候选，当前显示 19 个」 |
| 我的清单 | 19 张卡片 |
| 历史记录 | 「历史 9 条记录 · 最多保留 20 条」 |
| 添加页 | 输入框 + 平台选项 3 个（美团/淘宝闪购/不限）+ 保存按钮，都在 |
| 接口请求地址 | `https://…ap-shanghai.app.tcloudbase.com/api/items`（**公网地址**，不是本地） |
| 控制台报错 | **0 条** |

> ⚠️ 你看到的**条数会变**：每加一条 +1、首页抽一次签历史 +1。所以同伴的条数跟我的不一样是正常的，
> **只有"是 0"才算问题**。

## 四、同伴卡住了怎么办（三种最常见的）

| 症状 | 判断 | 回复他的话 |
|---|---|---|
| 「打不开，一直转圈」 | 他网络慢或拦在提示页 | 「先点页面中间那个『确定访问』按钮，点完再等 3 秒」 |
| 「打开是白屏」 | 大概率是真问题 | 让他按 F12 → Console 截图发你；同时你自己打开一遍，**你看得你没问题 → 是他那边（浏览器/网络）** |
| 「加了但刷新没了」 | ⚠️ **最严重**，说明写入没落库 | 立刻自己复现一次：打开公网 → 添加 → 刷新。你那边正常 = 他操作有误；你那边也没了 = 真 bug，今天就得查 |
| 「显示已有同名条目」 | **正常**，是防重复在起作用 | 「换个名字就行，不能加重复的 —— 这是故意的」 |
