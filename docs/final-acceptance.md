## ④ 前后端链路 —— PASS

```
浏览器 → CloudBase 静态托管（HTML/JS/图片）
       → 网关（CORS 白名单在网关上，函数里不加跨域头）
       → HTTP 云函数 api（Node 20，零依赖内置 fetch）
       → PostgREST（TCB_API_KEY）
       → PostgreSQL（items / history 两张表）
```

**链路的硬证据**：首页显示「共 68 个候选」= `GET /api/items` 的 `data.total`。
这两个数字来自完全不同的路径（一个渲染 DOM、一个读 JSON），能对上说明整条链路通。

**唯一出口**：`src/lib/api.js` 是前端**唯一**调后端的地方，没有散落的 `fetch`。
